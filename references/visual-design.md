# Visual Design System

## Establish tokens

Define the canvas, safe margins, grid, spacing scale, type scale, palette, corner radius, line weight, image treatment, chart colors, and citation style before creating slides.

Treat template, layout-gallery, and style metadata as routing hints. Inspect the actual preview and object structure before selecting a layout; do not rely on a category label that contradicts the visible composition.

For a 16:9 PPTX, use a 13.333 x 7.5 inch canvas. As starting ranges, use 28-40 pt titles, 18-24 pt body text, and 10-14 pt captions or citations. Adjust for the typeface, room size, and content density; never shrink text merely to make an overloaded slide fit.

Use one display family and one body family with reliable fallbacks. Use a neutral base plus one primary and one semantic accent. Preserve sufficient contrast and do not encode meaning by color alone.

## Compose slides

- Use a clear alignment system and stable safe margins.
- Make the primary message or visual dominant at thumbnail size.
- Vary composition while preserving tokens and recurring anchors.
- Prefer one strong chart, image, quotation, diagram, or number over a grid of generic cards.
- Avoid cards inside cards, decorative blobs, gratuitous gradients, and repeated centered layouts.
- Use whitespace to separate ideas, not to disguise missing content.
- Keep every object inside the canvas and prevent text from colliding with adjacent content.

## Select visuals

- Use real product screenshots for product claims.
- Use charts for comparisons, change, distribution, and relationships.
- Use diagrams for systems, sequences, responsibilities, and dependencies.
- Use generated raster art when the concept needs an original visual and factual inspection is not required.
- Use icons only when they improve scanning; keep their visual family consistent.
- Avoid atmospheric stock imagery when the audience needs to inspect the actual subject.

## Design data displays

- Choose the simplest chart that preserves the analytical point.
- Keep data values editable in native PPTX output.
- Show units, period, source, and relevant baselines.
- Direct-label important series and annotate the takeaway.
- Remove nonessential gridlines, legends, borders, and decimal precision.
- Do not use a chart when one number or a short comparison is clearer.

## Scenario overlays

- Executive and consulting: dense evidence, action titles, restrained palette, explicit implications.
- Academic: legible equations, one principal exhibit per results slide, citations on borrowed figures.
- Training: progressive disclosure, worked examples, recaps, and high visual-to-text correspondence.
- Product: real UI, workflow sequences, before/after evidence, clear feature hierarchy.
- Brand-controlled: inherit template tokens and assets; do not invent a competing visual language.
